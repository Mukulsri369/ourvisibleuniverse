# Nebula image guides

Original observatory JPEGs, downloaded without alteration. See sources.json for source pages, original URLs, full credits and native resolution. Images are used as colour and density guides for a procedural volume, with runtime projection and recolouring; unseen depth and reverse views are modelled, not photographed. Infrared/ultraviolet composites are identified in the object details. Pillars, Cosmic Cliffs, and Lagoon images show portions of their parent complexes; the volume extends those observed motifs rather than claiming a complete measured 3D survey. Some sources have less than 4K native resolution; procedural detail does not add observed pixels.
