# Galaxy overview appearance — 7 November 2026

This local rendering change preserves catalogue centres, adopted physical sizes, supplied sky orientation, IDs and source measurements. It changes the batched overview shader and its display profiles. It does not replace a galaxy with a photograph or add named stars, planets or measured internal coordinates.

## Data and visual inference

Every model receives a deterministic appearance profile. The 641 imported records use their existing source-derived morphology and projected axis-ratio handling. Where no individual image guide exists, population colours, unresolved depth, arm phase, clumps and dust texture are explicitly **morphology-family reconstruction**. An unfamiliar source is not represented as a newly observed detailed galaxy. Unknown orientation and colour measurements remain unknown in the catalogue.

The linear-light palette numbers are rendering choices informed by the sources below, not fitted RGB photometry. Existing B and V magnitudes, where both are present, can be carried as integrated B−V metadata; they are never turned into a fictitious resolved colour map. Optical/infrared composites use assigned filter colours, and VISTA/Webb colours must not be described as naked-eye appearance. Display gain and the minimum marker diameter make tiny galaxies discoverable; they are not flux calibration or physical enlargement of their catalogue sizes.

## Rendering and performance contract

The previous overview integrated twelve volume samples for every fragment, including unresolved markers. The new shader solves a finite-thickness ellipsoidal line-of-sight profile analytically. The camera basis is rotated into each galaxy’s local frame, so disks, ellipsoids, bars and absorbing lanes retain orientation while the view changes. Disk thickness avoids singular edge-on projections. The projected axis ratio is used for the existing irregular/spheroidal reconstruction convention; intrinsic depth remains illustrative.

There are distinct spiral, barred, elliptical, irregular, dwarf spheroidal, lenticular, blue compact, ring, flocculent, interacting and disk-starburst modes. Small points use the smooth continuum. Arms/clumps fade in by projected pixel size, and derivative smoothing suppresses subpixel arm shimmer. Bar/ring radii come from existing curated models. Their unmeasured detailed phases/textures remain reconstruction. M82’s plume, the LMC bar, Centaurus A’s dust lane and the Tadpole tail are explicit guide exceptions, not automatic features attached to all galaxies.

All points remain one batch. There are no per-record texture fetches, new draw calls, particle clouds, raymarch loops, runtime random numbers or per-frame profile allocations. Point size uses physical drawing-buffer height with a CSS-pixel visibility floor and CSS cap multiplied by the active device pixel ratio. Actual GPU/interaction measurements and visual acceptance belong to the parent motion-QA report; this document does not claim universal smoothness or literal telescope-image resolution.

Validation command: `node node_modules/tsx/dist/cli.mjs scripts/galaxy-overview-appearance-validation.ts`. The profile validation covers all current models, sourced provenance, absent photometry, morphology dispatch, finite shader parameters, observed exceptions and input immutability. Browser shader compilation and images are separate integration checks.
