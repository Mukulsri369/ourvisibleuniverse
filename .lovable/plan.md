# Physically scale extragalactic systems

## Goal
Make every extragalactic star system use the same real light-year coordinate scale as its host galaxy, removing the current galaxy-relative enlargement.

## Changes
- Define one physical conversion: 1 scene unit = 1 light-year and 1 AU = 1/63,241.077 scene units.
- Convert stellar radii from solar radii without visual inflation.
- Convert planet and moon radii, moon separations, rings, planetary orbits, and debris belts into physically proportionate dimensions.
- Apply the same conversion to Andromeda’s PA-99-N2 system and all data-driven galaxy systems.
- Retune visit-camera minimum distance, clipping, and focus distances so microscopic systems remain explorable after selection while staying effectively invisible at galaxy scale.
- Enable logarithmic depth precision for the extreme universe-to-planet zoom range.

## Verification
- Confirm the app builds cleanly.
- Open an extragalactic galaxy view and verify its system no longer appears oversized.
- Select an extragalactic planet and verify the close-up camera still resolves it without a blank frame or console error.
